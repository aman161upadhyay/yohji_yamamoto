# Yohji US benchmark methodology deck

Source files of the slide deck (28 slides) built with the Slides tool: `deck.json` is the index and `slides/*.html` holds one file per slide, at 1920x1080 in the design system in `design-system/`.

Several deep-dive, location and synthesis slides are placeholders marked `[...]` and `Placeholder` in the speaker notes. Fill them from the rows in `brands/` and `data/`.
